# BsxtBatch — AI working notes

Critical project settings, rules, and change history. Check this file before working.

## Critical settings / rules (do not break)

- **Inno Setup `AppId`** in `installer/BsxtBatch.iss`:
  `{{3D2A48FF-DC3E-4B9E-8111-AE056E8D63F0}` — must stay CONSTANT across all releases
  so upgrades replace instead of side-loading.
- **Never overwrite existing outputs.** Per-format check: skip file only when ALL
  selected outputs exist; write only the missing formats otherwise.
- **Output folder override** (v1.1.1): `ExportOptions.OutputDirectory` null/blank =
  outputs beside each source (default). When set, ALL outputs go there; the folder is
  created if missing and write-probed at batch start (before Photoshop is touched);
  unwritable = abort with clear message. CLI flag: `-o`/`--output-dir`.
- **Never modify originals**: every SaveAs uses `asCopy: true`; document is closed
  with `psDoNotSaveChanges` (2).
- **Skip policy**: files whose name already ends in `-BSXT`, and documents that
  already contain layers named `BSXT` or `Cleanup` (action not idempotent).
- COM: all Photoshop calls run on a dedicated **STA thread**; `DisplayDialogs = 3`
  (no dialogs); `OleMessageFilter` retries "application busy".
- Dev-only scratch dirs (`spike/`, `testdata/`, `plans/`) are git-ignored.
- Build/test: `dotnet build|test BsxtBatch.sln -c Release`.
- Installer build:
  `powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1 -Version <x.y.z>`
  (requires Inno Setup 6; output `installer\Output\BsxtBatch-Setup-<version>.exe`).
- Remote: https://github.com/3ricj/BackscatterRemovalWrapper (releases via GitHub).

## Version history

### v1.1.1 — 2026-09-28 (tag v1.1.1)
- **Output folder override**: GUI "Output folder:" row with Browse…/Clear buttons
  (read-only TextBox shows `OutputFolderDisplay`); default = same folder as each
  source. CLI: `-o`/`--output-dir <dir>`.
- Write-permission check on Start: `BatchProcessor.Run` creates the override dir if
  missing and probes it (`DirectoryHasWriteAccess`, temp-file write+delete); on
  failure throws `InvalidOperationException` — GUI shows MessageBox, CLI prints
  `Aborted: ...` and exits 4. Per-job source-folder check is skipped when overridden.
- Core: `ExportOptions.OutputDirectory` + `HasOutputOverride`;
  `OutputNameResolver.Resolve(source, format, outputDirectory)` overload; `ResolveAll`
  honors `options.OutputDirectory`. CLI now uses `new ExportOptions()` (not the
  `DefaultTiff` singleton) so `-o` mutation is safe.
- Tests: 58 passing (3 new override tests in OutputNameResolverTests).
- E2E (live Photoshop 27.10.0): `-f tif,psd -o testdata\out` wrote both outputs into
  the (auto-created) override folder, nothing in source folder; re-run skipped with
  "already exist"; `-o Z:\nope\dir` and an ACL-denied folder both aborted cleanly
  before connecting to Photoshop. WPF launches OK with new row.
- Version 1.1.1 in csproj + iss. Release: tag `v1.1.1`, asset `BsxtBatch-Setup-1.1.1.exe`.

### v1.1.0 — 2026-09-28 (tag v1.1)
- Release published on GitHub: tag `v1.1`, asset `BsxtBatch-Setup-1.1.0.exe` (42 MB).
  https://github.com/3ricj/BackscatterRemovalWrapper/releases/tag/v1.1
  (Repo has no `gh` CLI; releases were posted via GitHub REST using the credential
  stored in Git Credential Manager — see commit 357c837.)
- **Export options feature**: JPG / TIF / PSD checkboxes in the toolbar area; TIF is
  the default (only TIF checked at startup); at least one must remain selected —
  validation in `MainViewModel.RunAsync` (MessageBox + log) and a red inline warning.
- New `ExportOptions` + `ExportFormat` flags in Core; canonical write order TIF→PSD→JPG.
- PSD export keeps layers (`PhotoshopSaveOptions.Layers = true`,
  `MaximizeCompatibility = 3`); TIFF/JPG remain flattened.
- `OutputNameResolver.Resolve(source, format)` + `ResolveAll(source, options)`.
- `BatchProcessor.RunAsync(jobs, export, ct)`; per-format never-overwrite: existing
  outputs for one format don't block the others; detail lists what already existed.
- CLI front-end gained `-f jpg,tif,psd` (default `tif`), `ExportOptions.FromCsv` parsing.
- Removed now-unused `FileFormatClassifier.ExportsAsTiff`.
- Tests updated/added (54 passing). E2E verified against live Photoshop 27.10.0:
  all three formats written; PSD contains BSXT/Cleanup layer names; skip + partial-write
  paths verified; default = TIF only.
- Version bumped to 1.1.0 in `BsxtBatch.App.csproj` and `BsxtBatch.iss`.

### v1.0.x (pre-existing)
